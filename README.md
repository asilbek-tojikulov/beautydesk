# BeautyDesk — АРМ администратора салона красоты

Учебный проект по дисциплине «Введение в программную инженерию» (ТУИТ, группа М320-24, вариант 19).
Автор: Тожикулов Асилбек.

BeautyDesk — веб-система для администраторов сети из трёх салонов красоты в Ташкенте:
база клиентов, графики мастеров, журнал записи без накладок, касса (Payme, Click),
напоминания клиентам, отчёты и расчёт зарплаты мастеров.

## Структура репозитория

| Каталог | Содержимое |
|---|---|
| `docs/` | отчёты по практическим работам 1–11 (ТЗ, процесс, требования, архитектура, UI, паттерны, качество, безопасность, тестирование) |
| `docs/change_requests/` | шаблон и оформленные запросы на изменение |
| `src/booking/` | подсистема «Журнал записи» (Python) |
| `tests/` | модульные тесты pytest (ПР 11) |
| `.github/workflows/` | CI-конвейер GitHub Actions |

## Запуск тестов

```bash
pip install -r requirements-dev.txt
python -m pytest --cov=booking
```

## Ветвление

`main` — выпущенные версии, `develop` — интеграция, `feature/US-xx-...` — задачи из бэклога.
Подробно — в `CONTRIBUTING.md`.
